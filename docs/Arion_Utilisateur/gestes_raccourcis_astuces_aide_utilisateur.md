# Gestes et raccourcis utiles

PAIDEIA propose quelques raccourcis et gestes rapides qui dépendent de la zone utilisée. Les clics droits présentés ci-dessous remplacent volontairement le menu habituel de Windows dans la zone concernée.

## Raccourcis essentiels

| Raccourci | Action |
|---|---|
| `Ctrl + S` | Enregistrer l’activité ou la ressource en cours |
| `Alt + A` | Ouvrir ou fermer Arion dans l’éditeur |
| `Entrée` ou `Espace` | Activer le bouton ou le choix sélectionné |
| `Tab` / `Maj + Tab` | Passer au contrôle suivant ou précédent |
| Flèches | Parcourir les propositions, onglets et choix compatibles |
| `Échap` | Fermer d’abord le contexte en cours ; depuis le canevas d’une leçon, revenir aux chapitres ; depuis une fiche Ressources, revenir aux tuiles |

Dans Arion, les flèches parcourent les propositions, `Tab` complète la proposition et `Entrée` l’envoie.

Sur la trombine d'Arion, le clic droit détache directement l'assistant lorsqu'il est ancré et le réintègre lorsqu'il est détaché, sans ouvrir de menu. Quand Arion est détaché, un clic gauche sur sa trombine dans PAIDEIA ramène sa fenêtre au premier plan sans la réintégrer. Les commandes écrites de détachement et de réintégration restent également disponibles.

## Saisir et mettre en forme

- `Entrée` crée un paragraphe ou un nouvel élément de liste.
- `Maj + Entrée` crée un simple saut de ligne.
- Dans une liste, `Tab` et `Maj + Tab` modifient le retrait.
- Dans un tableau, `Tab` et `Maj + Tab` changent de cellule. Depuis la dernière cellule, `Tab` peut ajouter une ligne.
- Un clic droit sur l’icône **Tableau**, ou `Maj + F10` depuis une cellule, ouvre les commandes du tableau.
- Dans l’activité HTML personnalisé, `Tab` insère deux espaces dans le code.

## Gagner du temps dans l’éditeur

- Faites glisser une activité ou une activité favorite pour choisir directement sa position.
- Faites un clic droit sur la barre des favoris pour réorganiser les activités favorites.
- Un clic sur **Dupliquer** reproduit immédiatement l’activité ; un clic droit sur cette commande prépare sa copie vers un autre emplacement.
- Un clic droit sur une zone d’insertion permet de coller l’activité copiée.
- Un clic droit sur la poignée de déplacement copie la référence complète de l’activité.
- Sur les longues pages, maintenez une flèche de défilement pour avancer en continu ou double-cliquez dessus pour atteindre directement le début ou la fin.

## Images et points interactifs

- **Points d’intérêt** : clic droit sur un point pour le supprimer ; faites-le glisser pour le déplacer.
- **Trouver les éléments** : clic droit sur un marqueur pour le retirer.
- Dans un polygone de **Trouver les éléments**, cliquez sur un segment pour ajouter un sommet, faites glisser un sommet pour le déplacer et faites un clic droit dessus pour le supprimer.
- **Image 360** : en mode de placement, faites un clic droit dans la scène pour ajouter un point à l’endroit visé.
- Pour certains bandeaux et fonds, un double-clic active le repositionnement. Faites glisser l’image puis utilisez `Échap` ou cliquez à l’extérieur pour terminer.
- Dans l’outil d’annotation, `Ctrl + Z` annule, `Ctrl + Y` rétablit et `Suppr` retire l’objet sélectionné.

## À propos du copier-coller

`Ctrl + C`, `Ctrl + X` et `Ctrl + V` concernent le texte lorsque le champ actif les autorise. Ils ne copient pas une activité entière. Pour déplacer le contenu complet d’une activité, utilisez les commandes de copie et de collage propres à l’éditeur PAIDEIA.
