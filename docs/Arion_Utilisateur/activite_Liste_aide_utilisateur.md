# Activité Liste

L’activité **Liste** présente des éléments sous forme de liste à puces ou
numérotée.

## Configuration

Saisissez les éléments dans l’éditeur Rich Text, puis choisissez le type de
liste et le niveau de retrait avec les outils proposés. Chaque élément doit
rester une unité lisible.

Vous pouvez combiner une liste avec des titres, du texte, des liens ou des
tableaux lorsque le champ le permet.

## Conseils

Utilisez une liste pour des éléments de même nature et gardez une structure de
niveaux simple. Vérifiez les retraits, les retours à la ligne et les listes
longues dans l’éditeur, l’aperçu LMS et le SCORM.
