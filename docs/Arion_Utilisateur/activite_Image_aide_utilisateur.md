# Activité Image

L’activité **Image** affiche une image dans la leçon, avec un texte alternatif
et les réglages d’affichage disponibles.

## Configuration

Sélectionnez l’image, renseignez sa description alternative et choisissez sa
largeur, sa hauteur ou son recadrage lorsque ces réglages sont proposés.
Marquez-la comme décorative si elle n’apporte aucune information pédagogique.

L’image est copiée dans le projet ; le fichier original reste inchangé.

## Vérification

Contrôlez les proportions, la lisibilité et le comportement sur petit écran.
Une image informative doit posséder une description alternative utile. Testez
le rendu dans l’éditeur, l’aperçu LMS, le SCORM et le PDF.
