# Activité Onglets

L’activité **Onglets** répartit un contenu en plusieurs panneaux accessibles
depuis une barre d’onglets.

## Configuration

Ajoutez un onglet, donnez-lui un titre court et saisissez son contenu Rich Text.
Vous pouvez ajouter une image lorsque le panneau le permet. Réordonnez ou
supprimez les onglets pour construire le parcours souhaité.

## Utilisation par l’apprenant

L’apprenant clique sur un onglet pour afficher son contenu. Les titres doivent
être compréhensibles sans ouvrir chaque panneau.

Vérifiez l’ordre, le changement d’onglet, les contenus longs et l’affichage
mobile dans l’aperçu LMS et le SCORM.
