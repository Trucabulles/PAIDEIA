# Activité Fichier

L’activité **Fichier** met un document à disposition de l’apprenant sous la
forme d’un lien ou d’un bouton de téléchargement.

## Configuration

Sélectionnez le fichier à intégrer, puis renseignez son libellé pédagogique et
les textes complémentaires proposés. Le fichier est copié dans le projet ; le
fichier original n’est pas modifié.

Le libellé doit permettre de comprendre le contenu du document avant de le
télécharger. N’utilisez pas un chemin local comme information destinée à
l’apprenant.

## Utilisation et vérification

L’apprenant clique sur le fichier pour l’ouvrir ou le télécharger selon son
navigateur et sa plateforme LMS. Testez le lien, le nom affiché et le contenu
du fichier dans l’aperçu LMS et dans le SCORM.
