# Activité Note

L’activité **Note** met en évidence une information courte : rappel, conseil,
attention ou définition.

## Configuration

Saisissez le contenu dans l’éditeur Rich Text, puis choisissez le pictogramme et
l’accent visuel proposés. Sept pictogrammes sont disponibles. Décochez
**Afficher le pictogramme** pour utiliser uniquement le contenu Rich Text, sans
espace vide à gauche ; votre choix de pictogramme reste mémorisé si vous le
réaffichez ensuite. Par défaut, sa couleur est identique à celle de la bordure.
Décochez **Identique à la bordure** pour choisir une couleur de pictogramme
indépendante ; cette couleur reste mémorisée si vous rétablissez ensuite la
liaison. Gardez un texte suffisamment court pour que la note conserve
son rôle de repère.

## Utilisation et vérification

L’apprenant lit la note comme un encadré intégré au parcours. Vérifiez le
contraste, les listes, les liens et les coins du bloc dans l’aperçu LMS et le
SCORM.
