# Activité Citation

L’activité **Citation** met en valeur une citation, son auteur et, si besoin,
un complément explicatif.

## Configuration

Saisissez la citation dans le champ Rich Text, puis renseignez l’auteur et les
informations complémentaires proposées par l’éditeur. Vous pouvez ajouter un
portrait ou une image associée lorsque le champ média est disponible.

## Rendu

La citation est présentée comme un bloc visuellement distinct du texte
courant. Les styles Rich Text explicitement choisis sont conservés.

## Bonnes pratiques

Vérifiez l’orthographe du texte et le nom de l’auteur. Une description
alternative doit être fournie pour une image informative. Contrôlez le rendu
dans l’aperçu LMS, le SCORM et le PDF si la citation est imprimée.
