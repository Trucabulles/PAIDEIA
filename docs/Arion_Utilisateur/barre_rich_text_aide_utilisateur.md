# Barre Rich Text

La barre Rich Text apparaît lorsqu’un champ de texte peut être mis en forme. Elle agit sur le texte sélectionné ou, lorsqu’aucune sélection n’est active, sur le texte saisi ensuite.

## Mise en forme courante

Selon le champ, la barre permet notamment de choisir :

- le type de paragraphe ou un niveau de titre ;
- la police et la taille ;
- l’alignement et l’interligne ;
- une liste à puces ou numérotée ;
- le retrait ;
- le gras, l’italique, le soulignement et le barré ;
- la couleur du texte et le surlignage ;
- un lien, une image ou un tableau lorsque le champ l’autorise.

Les commandes visibles dépendent du champ édité. Un titre, une consigne, une cellule de tableau ou un texte pédagogique ne proposent pas forcément les mêmes outils.

Le menu propose **Paragraphe**, **Titre principal**, puis **Titre niveau 2** à **Titre niveau 5**. Les tailles décroissantes rendent leur hiérarchie visible. Ces choix correspondent aux niveaux de titre H1 à H5 : choisir le niveau selon la structure du texte, pas seulement selon la taille souhaitée.

La liste des polices affiche chaque nom dans sa propre police lorsque son fichier est disponible. Elle distingue les polices PAIDEIA, celles du projet et vos polices personnelles. Le champ supérieur indique la police appliquée ; seul le survol ou le déplacement au clavier souligne une entrée dans la liste. Si plusieurs polices sont choisies rapidement, le dernier choix prévaut.

Les menus Paragraphe et listes se ferment au clic extérieur ou sur une autre commande. Les commandes de liste conservent la sélection pour essayer un autre symbole ou une autre numérotation sans sélectionner à nouveau le texte.

Dans les champs qui proposent un fond, le bouton de fond ouvre son choix de couleur. Sa petite flèche ouvre uniquement **Opacité**, réglable de 0 à 100 %. Il s'agit d'un seul fond pour tout le champ, distinct du surlignage du texte. Le filet vertical distingue les deux zones du bouton.

## Sélection et portée

Sélectionner précisément le texte avant d’appliquer un format. Pour une liste, le style s’applique aux éléments sélectionnés tout en conservant la structure de la liste. Dans un tableau, une sélection de texte ne modifie que ce passage. Sélectionner une cellule entière ou plusieurs cellules applique la propriété choisie à leur contenu ; les autres propriétés sont conservées.

Le bouton **Effacer le formatage** retire les styles de texte appliqués sans supprimer le contenu. Les éléments structurels nécessaires au champ, comme son fond propre, sont conservés.

Ce bouton est représenté par une **gomme bicolore**. Le bouton **Sélectionner tout**, représenté par des carrés superposés avec une coche, sélectionne le contenu du champ actif.

## Commandes du tableau

L'icône de paramètres du tableau ouvre son menu. Il reste ouvert après une modification, y compris **Annuler** ou **Rétablir**, pour enchaîner les réglages. Recliquer sur l'icône le ferme. Quitter le champ Rich Text valide son contenu et ferme les outils.

Une commande sur plusieurs cellules agit sur toute la sélection. **Scinder horizontalement** crée une séparation haut/bas ; **Scinder verticalement** crée une séparation gauche/droite. **Scinder les cellules** défait les fusions des cellules sélectionnées.

Pour insérer des lignes ou colonnes, la commande compte chaque ligne ou colonne sélectionnée une seule fois et ajoute un bloc avant ou après la sélection. La suppression retire les lignes ou colonnes concernées ; sélectionner toutes les lignes ou toutes les colonnes puis les supprimer retire le tableau.

Dans **Mise en forme**, **Mixte** indique que les cellules sélectionnées ont des valeurs différentes. Choisir une valeur applique cette seule propriété à toutes les cellules sélectionnées. Le tableau est limité à **32 lignes et 32 colonnes** : si une insertion ou une scission dépasserait ce plafond, un message l'indique et aucune partie de l'opération n'est appliquée.

## Propriétés d’une image intégrée

Double-cliquez sur une image intégrée au texte. Dans **Affichage**, cochez **Coins arrondis** pour arrondir cette image ou **Autoriser le zoom** pour l’agrandir d’un clic en aperçu et dans le SCORM. Les deux options sont décochées par défaut. Cliquez sur **Appliquer** pour les enregistrer.

## Conseils

Après une combinaison de titre, taille et liste, vérifier le résultat visuel et le niveau affiché dans la barre. Les styles explicitement choisis dans le texte sont prioritaires sur les réglages hérités. Contrôler ensuite l’aperçu LMS si le formatage est important pour la lecture.
