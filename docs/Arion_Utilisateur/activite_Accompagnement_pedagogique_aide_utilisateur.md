# Activité Accompagnement pédagogique

L’activité **Accompagnement pédagogique** ajoute un commentaire, un conseil ou
une aide directement dans le parcours de la leçon.

## Configuration

Saisissez le contenu dans l’éditeur Rich Text et choisissez l’apparence ou le
type d’accompagnement proposé. Utilisez ce bloc pour guider l’apprenant sans
interrompre son activité.

## Utilisation par l’apprenant

L’apprenant lit l’accompagnement à l’endroit où il apparaît dans la leçon. Le
contenu peut expliquer une notion, rappeler une méthode ou orienter vers la
prochaine étape.

## Conseils

Restez bref et placez l’aide près de l’information concernée. Vérifiez le
contraste, les liens et le rendu dans l’aperçu LMS et le SCORM.
