# Activité Image et texte

L’activité **Image et texte** associe une image à un contenu explicatif dans
une disposition verticale ou latérale.

## Configuration

Importez l’image, fournissez sa description alternative puis saisissez le
texte dans l’éditeur Rich Text. Choisissez la disposition proposée pour placer
le média à côté du texte ou au-dessus de celui-ci.

L’image est intégrée au projet sans modifier le fichier original. Ajustez son
recadrage ou son apparence lorsque les options sont disponibles.

## Conseils

Le texte doit rester compréhensible même si l’image n’est pas visible. Vérifiez
le centrage, les proportions, la lecture mobile et le rendu dans l’aperçu LMS,
le SCORM et le PDF.
