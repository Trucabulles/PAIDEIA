# Activité Images multiples

L’activité **Images multiples** présente plusieurs images dans une même
activité, avec leurs informations associées.

## Configuration

Ajoutez les images dans l’ordre souhaité, renseignez leur texte alternatif et
complétez les champs de titre ou de description disponibles. Vous pouvez
remplacer ou supprimer chaque image individuellement.

## Utilisation et conseils

L’apprenant consulte la série d’images dans l’ordre de présentation. Utilisez
des images de dimensions et de poids raisonnables, et évitez de répéter dans la
description ce qui est déjà clairement indiqué dans le texte voisin.

Vérifiez la grille, les légendes, les proportions et l’affichage mobile dans
l’aperçu LMS et le SCORM.
