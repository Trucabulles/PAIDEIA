# Activité Tri de cartes

L’activité **Tri de cartes** demande de classer des cartes dans les catégories
appropriées.

## Configuration

Créez les catégories, ajoutez les cartes et indiquez la catégorie correcte de
chacune. Renseignez le feedback global ou celui associé aux cartes lorsque ces
options sont disponibles.

## Utilisation par l’apprenant

L’apprenant dépose chaque carte dans une catégorie puis valide ou poursuit
selon le fonctionnement affiché. Une carte mal classée peut nécessiter une
nouvelle tentative ; l’activité est terminée lorsque toutes les cartes sont
correctement classées et que la sortie demandée est activée.

Utilisez des catégories distinctes et des cartes non ambiguës. Testez les
classements, le feedback, le clavier et le tactile dans l’aperçu LMS et le
SCORM.
