# Activité HTML personnalisé

L’activité **HTML personnalisé** permet d’intégrer un contenu HTML conçu pour
un besoin particulier de la leçon.

## Configuration

Saisissez ou collez le code dans l’éditeur prévu à cet effet, puis ajoutez une
description de ce que le contenu présente. La description aide à comprendre
l’activité dans l’éditeur et lors de la relecture.

Le HTML personnalisé est destiné aux contenus maîtrisés par le concepteur.
N’y copiez pas de code provenant d’une source inconnue et ne l’utilisez pas
pour remplacer une activité native lorsque celle-ci répond au besoin.

## Vérification

Testez le rendu, les liens, les interactions et le comportement responsive dans
l’aperçu LMS et le SCORM. Un contenu HTML peut avoir un rendu différent selon
le navigateur ou la plateforme qui l’héberge.
