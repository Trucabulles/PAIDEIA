# Images, recadrage, annotation et texte alternatif

PAIDEIA permet de préparer une image avant son utilisation dans une activité : choisir la source, la recadrer, l’annoter et renseigner les informations utiles à sa lecture.

## Recadrer une image

Ouvrir l’outil de recadrage depuis l’éditeur de l’image. Ajuster la zone visible, puis valider pour enregistrer le cadrage. Le recadrage modifie la présentation de l’image dans l’activité ; il ne redimensionne pas arbitrairement la source originale.

Pour une image très petite, PAIDEIA peut afficher un avertissement de lisibilité. Une image extrêmement petite peut être refusée pour l’annotation. Annuler ne modifie pas l’image.

## Annoter une image

Ouvrir l’éditeur d’annotation, ajouter les formes ou repères nécessaires, puis les déplacer et les ajuster sur l’image. Le zoom de travail sert uniquement à faciliter la précision ; il ne change pas les dimensions pédagogiques ou celles de l’export.

Valider l’annotation pour l’associer à l’image de l’activité. Si la source est remplacée, l’ancienne annotation n’est pas réappliquée automatiquement : il faut la vérifier ou la recréer sur la nouvelle image.

## Texte alternatif et image décorative

Le texte alternatif décrit l’information portée par l’image pour les personnes qui ne peuvent pas la voir. Il doit être court, précis et utile dans le contexte de la leçon. Ne pas recopier une légende déjà présente si elle fournit la même information.

Si l’image n’apporte aucune information et sert uniquement à décorer, la marquer comme **décorative** plutôt que d’inventer une description. Le statut et le texte alternatif sont gérés par occurrence : deux utilisations d’une même image peuvent donc avoir des informations différentes.

PAIDEIA peut signaler les images sans ALT dans l’éditeur et dans le résumé du chapitre. Les informations sont restituées dans l’aperçu LMS et le SCORM ; elles ne constituent pas, à elles seules, une validation complète de l’accessibilité.

## Vérifier avant diffusion

Après un recadrage ou une annotation, contrôler l’image dans l’éditeur, l’aperçu LMS, le SCORM et le PDF lorsque celui-ci est prévu. Vérifier également que le texte alternatif correspond bien à l’image effectivement affichée.
