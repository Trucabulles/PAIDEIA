# Activité En-tête

L’activité **En-tête** crée un bandeau visuel pour introduire une partie de la
leçon ou mettre en valeur un titre.

## Configuration

Saisissez le titre et le contenu proposés par l’éditeur, puis choisissez une
image ou une couleur de fond si nécessaire. Réglez la hauteur et l’espacement
avec mesure : plusieurs lignes, une grande police ou un interligne élevé
augmentent naturellement la hauteur du bandeau.

Les réglages de texte et les images doivent rester lisibles sur les différents
formats d’écran. Utilisez une description alternative pour une image
informative.

## Vérification

Contrôlez l’alignement, le contraste et la hauteur dans l’éditeur, l’aperçu LMS
et le SCORM. Évitez de placer trop de texte dans un bandeau destiné à un titre.
