# Activité Audio

L’activité **Audio** permet d’intégrer un enregistrement dans une leçon et de
le compléter par un titre, une description ou un contenu Rich Text.

## Configuration

Importez le fichier audio depuis l’éditeur, puis renseignez les textes utiles.
Le fichier est copié dans le projet ; l’original sur l’ordinateur n’est pas
modifié. Utilisez l’onglet `Apparence` pour régler le fond extérieur lorsque
ces options sont disponibles.

## Utilisation par l’apprenant

L’apprenant utilise les commandes du lecteur pour lancer, mettre en pause,
avancer ou régler le volume. Ajoutez une transcription ou un résumé lorsque le
contenu audio est nécessaire à la compréhension.

## Vérification

Testez le chargement, la lecture, la pause et le volume dans l’aperçu LMS et
dans le SCORM. Vérifiez également le nom du fichier et les textes associés.
