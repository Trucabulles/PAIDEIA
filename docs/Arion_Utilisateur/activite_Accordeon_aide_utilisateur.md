# Activité Accordéon

L’**Accordéon** regroupe plusieurs contenus dans des panneaux repliables. Il
permet de présenter une information détaillée sans afficher tout le contenu en
même temps.

## Créer un accordéon

Ajoutez un panneau, renseignez son titre puis saisissez son contenu dans
l’éditeur Rich Text. Vous pouvez ajouter, réordonner et supprimer les panneaux.
Chaque panneau peut également contenir une image lorsque cette option est
proposée.

## Utilisation par l’apprenant

L’apprenant clique sur le titre d’un panneau pour l’ouvrir ou le refermer. Les
contenus ouverts restent accessibles pendant la consultation de l’activité.

Utilisez des titres courts et explicites afin que l’apprenant sache rapidement
quel panneau consulter.

## Apparence et vérification

Les contenus Rich Text conservent leur mise en forme. Vérifiez les panneaux,
les images et les textes longs dans l’aperçu LMS et dans le SCORM.
