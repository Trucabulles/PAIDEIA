# Activité Texte

L’activité **Texte** permet de rédiger un contenu pédagogique structuré avec
l’éditeur Rich Text.

## Rédiger le contenu

Saisissez le texte puis utilisez la barre Rich Text pour appliquer des titres,
listes, alignements, liens, tableaux et styles disponibles. Les retours à la
ligne et les retraits doivent servir la structure du contenu.

Le texte s’adapte à la largeur disponible. Les mots très longs ou les chaînes
techniques doivent rester lisibles sans provoquer de débordement du champ.

## Conseils

Utilisez les niveaux de titre dans l’ordre, aérez les paragraphes et vérifiez
les tableaux sur petit écran. Contrôlez la parité entre l’éditeur, l’aperçu LMS,
le SCORM et le PDF lorsque le contenu est exporté.
