# Activité Séparateur repéré

L’activité **Séparateur repéré** introduit une séparation visuelle accompagnée
d’un repère ou d’un intitulé.

## Configuration

Renseignez le libellé du repère et choisissez le style disponible. Le texte
doit annoncer clairement la partie qui suit.

## Vérification

Vérifiez l’alignement, le contraste et l’espacement avec les activités voisines
dans l’éditeur, l’aperçu LMS et le SCORM.
