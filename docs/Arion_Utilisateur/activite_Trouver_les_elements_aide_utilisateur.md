# Activité Chercher dans l’image

L’activité **Chercher dans l’image** demande à l’apprenant de repérer des
éléments directement sur une image.

## Configuration

Importez l’image, renseignez sa description alternative, puis créez les zones
ou éléments attendus avec l’outil proposé. Délimitez chaque zone assez
précisément pour éviter les réponses ambiguës.

## Utilisation par l’apprenant

L’apprenant clique ou marque les éléments demandés dans l’image. La validation
et le feedback indiquent le résultat selon la configuration de l’activité.

## Conseils

Vérifiez le placement des zones, le contraste, le comportement tactile et les
tentatives dans l’aperçu LMS et le SCORM. Utilisez une image suffisamment nette
pour que les éléments attendus soient identifiables.
