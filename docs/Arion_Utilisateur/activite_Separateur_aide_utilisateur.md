# Activité Séparateur

L’activité **Séparateur** crée une séparation visuelle entre deux parties de la
leçon.

## Configuration

Choisissez le style proposé et ajoutez éventuellement un repère ou un libellé
si l’activité le permet. Utilisez-le pour structurer la lecture, pas pour
remplacer un titre de section.

## Vérification

Contrôlez l’espacement, la visibilité du trait et le rendu sur petit écran dans
l’éditeur, l’aperçu LMS et le SCORM.
