# Documentation livrée avec les sources PAIDEIA

Ce dossier contient uniquement les documents nécessaires à la construction de PAIDEIA ou destinés aux utilisateurs, et aux mainteneurs.

- [Reprise du développement et des builds](Reprise_Depuis_GitHub.md) : installation d'un poste Windows, démarrage du projet, contrôles et préparation des livraisons.
- [Aide utilisateur d’Arion](Arion_Utilisateur/) : fiches indexées dans l’application lors du build. Les fichiers Markdown eux-mêmes ne sont pas embarqués.
- [Guide utilisateur PDF](Guide_Utilisateur/PAIDEIA_Guide_utilisateur.pdf) : édition embarquée et accessible depuis le menu Informations.
- [Cartographie technique](Architecture/Cartographie_Technique.md), [carte des composants](Architecture/Component_Map.md), [flux de données](Architecture/Data_Flow.md) et [dictionnaire de maintenance](Architecture/Dictionnaire_Cartographie_Maintenance.md). Ces cartes portent leur propre date de vérification ; leur actualisation de fond reste à faire.

Les autres fiches, audits, cadrages, arbitrages et sources éditoriales sont conservés localement dans `Dev_Documentation/`, hors Git. Pour les documents présents dans les deux dossiers, la version partagée est éditée ici puis synchronisée vers la copie locale. Le DOCX du guide utilisateur reste une source de travail locale ; son PDF publié est régénéré dans ce dossier.
