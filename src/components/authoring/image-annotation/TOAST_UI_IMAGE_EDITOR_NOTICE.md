# TOAST UI Image Editor Notice

The native PAIDEIA image annotation tool keeps TOAST UI Image Editor as a UX and behavior reference for annotation families, controls, handles, and icon direction.

The implementation is native PAIDEIA code and does not use TOAST UI Image Editor as its runtime.
