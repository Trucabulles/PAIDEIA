Déposer ici les PNG d’Axel avec ces noms exacts :

- `question/question.png`
- `neutral/neutral.png`
- `positive/positive.png`
- `negative/negative.png`

Chemins attendus par l’application :

- `default-characters/axel/question/question.png`
- `default-characters/axel/neutral/neutral.png`
- `default-characters/axel/positive/positive.png`
- `default-characters/axel/negative/negative.png`

Vous pouvez aussi mettre plusieurs PNG par dossier :

- `question/1.png`
- `question/2.png`
- `positive/1.png`
- `positive/2.png`

L’application détecte automatiquement toutes les images présentes. La première
par ordre alphabétique sert de pose par défaut pour l’état concerné.
