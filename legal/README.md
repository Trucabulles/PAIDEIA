# Licence PAIDEIA

Le fichier `../LICENSE` est la version texte de référence publiée avec le code source.

- `Licence-PAIDEIA.docx` est la copie mise en forme proposée au téléchargement dans l'application.
- `Licence-PAIDEIA.rtf` est la copie mise en forme de la licence française.
- `Licence-PAIDEIA.txt` est la copie texte utilisée par les installateurs Windows MSI et NSIS afin d'éviter l'imbrication d'un RTF Word complexe dans le contrôle de licence WiX.

Ces quatre représentations doivent conserver le même contenu juridique. Toute modification de la licence doit être appliquée au document Word, puis répercutée dans `LICENSE`, dans le fichier RTF et dans le fichier texte destiné aux installateurs avant publication.

La version anglaise de la licence est fournie en TXT, RTF et DOCX dans les fichiers `License-PAIDEIA-International-EN.*`. Ces formats reprennent le même texte anglais, disponible dans l’application et dans les livrables.

## Licences tierces

Le dossier conserve également les textes de licence des composants tiers
utilisés ou ayant servi de référence directe à PAIDEIA :

- `pdfmake-LICENSE.txt` : pdfmake ;
- `React-LICENSE.txt` et `React-DOM-LICENSE.txt` : interface et rendu HTML,
  également utilisés pour préparer certaines activités du PDF A4 ;
- `html-entities-LICENSE.txt` : décodage des caractères HTML ;
- `Plyr-LICENSE.txt` : lecteur audio et vidéo Plyr 3.8.4 ;
- `Toast-UI-Image-Editor-LICENSE.txt` : TOAST UI Image Editor, référence
  d’interface, de comportement et d’iconographie pour l’outil natif
  d’annotation d’image.

La liste descriptive et les liens vers les sources sont maintenus dans
`../THIRD_PARTY_NOTICES.md`.
